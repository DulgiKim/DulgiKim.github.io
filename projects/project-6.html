AI 활용 & 워크플로우 자동화

👤 개발 워크플로우 개선 / 자동화 🤖 주 사용 에이전트: Claude Code
Claude Code Cursor Unity MCP Automation CI/CD Procedural Generation
게임 하나를 만드는 프로젝트가 아니라, AI를 실제 개발 업무에 어떻게 붙이고 있는지를 정리한 페이지입니다.

개요

코드 작성 자체보다, 반복되는 업무와 사람 간 커뮤니케이션 손실을 줄이는 데 AI를 쓰고 있습니다. 주로 사용하는 AI 코딩 에이전트는 Claude Code이며, 일상적인 개발 외에도 회의 내용을 실제 개발 가이드로 연결하는 기능, 빌드·QA 자동화, 게임 내 프로시저널 콘텐츠 생성까지 여러 영역에 적용해보고 있습니다.

AI 코딩 에이전트 활용

  • Claude Code를 주 에이전트로 사용하며, 회의 내용을 바탕으로 이번 스프린트에 어떤 콘텐츠를 만들어야 하는지 코드 상에서 가이드를 제시해주는 기능을 만들어 팀 내 일종의 PM 보조 역할을 하도록 구성
  • 레거시 코드 리팩토링 및 마이그레이션에 Claude Code를 활용해 오래된 시스템을 정리하는 작업 시간 단축
  • Unity 6로 업데이트하면서, Unity MCP를 연결해 에디터 상태(씬 계층 구조, 컴포넌트, 콘솔 로그 등)를 Claude Code가 직접 읽고 코드를 작성하도록 개발 방식을 전환
  • Cursor는 보조적으로 병행 사용

사내 자동화 파이프라인

  • CI/CD와 연동한 빌드·배포 자동화
  • QA/테스트 자동화로 반복 검증 작업 축소

게임 내 AI 콘텐츠

  • 퍼즐 스테이지 제작 : 미션, 특수 블럭의 갯수 및 종류, 맵의 모양을 다양하고 빠르게 제작하기 위해 AI 에이전트에게 만들어진 스테이지들을 학습시키고 이를 토대로 신규 스테이지를 제작

회고

AI를 코드 자동완성 수준이 아니라, 회의·기획 같은 사람 간 커뮤니케이션과 개발 파이프라인 사이의 손실을 줄이는 도구로 붙였을 때 체감 효율이 가장 컸습니다. 앞으로도 반복 업무를 하나씩 걷어내면서, 실제로 유의미하게 시간을 아껴주는 지점을 찾아 적용 범위를 넓혀갈 계획입니다.
